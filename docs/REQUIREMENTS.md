# Conversational Scheduling Assistant

The LiveX take-home asks for a Python chatbot that lets a founder manage their Cal.com bookings through plain conversation.

## Requirements

| Action | What the user can do |
| --- | --- |
| Book | Describe a meeting, supply any missing details, and choose an available time. |
| View | Ask “What’s on my calendar tomorrow?” and see their Cal.com bookings in their local time. |
| Cancel | Identify a meeting in conversation and cancel it. |
| Reschedule | Identify an existing meeting and move it to an available time. |

Use the Cal.com REST API. The conversational layer can use any LLM provider. An interactive web UI is a bonus.

## Submission

Submit within five days of receiving the assignment. Include a public or shared GitHub repository with a README explaining how to set up and run the chatbot, plus a short screen recording demonstrating the four actions.
